# 拼贴一下 · 抖音小程序原型

这是一个独立的抖音小程序原型项目，核心流程是：模板库 → 三宫格 / 四宫格 / 九宫格 → 主题与月份 → 上传照片 → 拼贴编辑 → 手绘标注 → 保存到相册。

## 真实模板体系

模板库按当前素材分成：

- 三宫格、四宫格、九宫格；
- 生日月历模板；
- 白金日历、黑金千金、黑红派对、复古棕色、豹纹等主题；
- 后续可继续增加颜色、主题和更多模板集合。

`assets/templates/` 中的缩略图来自你提供的模板参考截图裁切，`assets/references/` 保留了完整参考图，方便后续继续扩展模板。

## 状态流程

| 状态 | 文件 | 触发 | 主操作 | 下一步 |
| --- | --- | --- | --- | --- |
| 模板库与分类 | `home.html` | 进入小程序 | 选择场景或版式 | 版式库或生日设置 |
| 版式库 | `layout-library.html` | 点击三宫格 / 四宫格 / 九宫格 | 选择版式 | 主题和月份 |
| 生日设置 | `birthday-settings.html` | 选择生日九宫格 | 选择月份、日历和主题，开启手绘 | 上传 9 张照片 |
| 九宫格上传 | `birthday-upload.html` | 进入生日模板 | 批量上传并补齐 9 张照片 | 九宫格编辑 |
| 九宫格编辑 | `birthday-editor.html` | 照片数量满足 | 换顺序、替换、换主题、手绘 | 手绘或保存 |
| 手绘标注 | `annotation.html` | 编辑页点击手绘 | 选择颜色、画笔、文字 | 应用标注 |
| 普通模板选图 | `upload.html` | 三宫格 / 四宫格模板 | 上传照片 | 普通模板编辑 |
| 普通模板编辑 | `editor.html` | 照片数量满足 | 调整裁切、版式、照片 | 保存中 |
| 保存中 | `saving.html` | 点击保存拼贴 | 等待生成完成 | 保存完成 |
| 保存完成 | `result.html` | 图片生成成功 | 再次保存 / 继续编辑 | 编辑或保存流程 |
| 上传失败 | `upload-error.html` | 文件过大或网络中断 | 换一张 / 重试上传 | 回到选图 |
| 我的模板 | `my-templates.html` | 点击收藏或我的 | 再次使用收藏模板 | 对应设置页 |

## 设计系统

- 方向：可爱卡通 + 真实模板画廊。
- 变量入口：[tokens.css](tokens.css)。
- 共享组件样式：[app.css](app.css)。
- 图标：[icons.svg](icons.svg)。
- 参考模板素材：`assets/references/` 与 `assets/templates/`。

页面之间使用真实 HTML 链接串联，方便在设计工作台里演示从版式选择到月份设置、上传、编辑和手绘的完整流程。当前原型表达视觉、状态和跳转，不包含真实上传、裁切、手绘保存、相册写入或抖音开放能力。
