# 拼贴一下 · 抖音小程序原型

这是一个独立的抖音小程序原型项目，核心流程是：选择拼贴模板 → 上传照片 → 编辑拼贴 → 保存到相册。

## 预览

直接打开 `home.html`，或用设计工作台打开整个目录。所有页面都使用 375×812 小程序画幅，并按同一套 `tokens.css` 和 `app.css` 渲染。

## 状态流程

| 状态 | 文件 | 触发 | 主操作 | 下一步 |
| --- | --- | --- | --- | --- |
| 模板浏览 | `home.html` | 进入小程序 | 选择模板 / 直接拼贴 | 模板详情或选图 |
| 模板详情 | `template-detail.html` | 点击模板卡片 | 使用这个模板 | 选图上传 |
| 选图未完成 | `upload.html` | 进入模板后 | 上传第 3 张照片 | 编辑拼贴 |
| 编辑拼贴 | `editor.html` | 照片数量满足 | 调整裁切、版式、照片 | 保存中 |
| 保存中 | `saving.html` | 点击保存拼贴 | 等待生成完成 | 保存完成 |
| 保存完成 | `result.html` | 图片生成成功 | 再次保存 / 继续编辑 | 编辑或保存流程 |
| 上传失败 | `upload-error.html` | 文件过大或网络中断 | 换一张 / 重试上传 | 回到选图 |

## 设计系统

- 方向：可爱卡通，粉黄糖果色、大圆角、圆体感字体。
- 变量入口：`tokens.css`。
- 共享组件样式：`app.css`。
- 图标：`icons.svg`。
- 图片：`assets/` 中的 AI 示意图，上线前需要替换成真实用户照片或正式素材。

页面之间使用真实 HTML 链接串联，方便在设计工作台里演示主路径和失败恢复路径。当前原型只表达视觉、状态和跳转，不包含真实上传、裁切、保存或抖音开放能力。
